# 默认展示与体验访问

项目启动后，`/` 始终打开 NOVA 原 IP 图片与固定校园示例。这里可以切换现场理解、回复表达和事项接续三个示例，也可以观看 `/showcase/` 中的产品影片。公开页不加载功能应用，不读取个人事项，不调用模型或请求麦克风权限。

## 启动与解锁

```powershell
npm install
npm start
```

默认地址为 `http://127.0.0.1:5178/`，本地 `.env` 中的 `HOST` / `PORT` 可以覆盖。未设置体验 Key 时只开放示例展示；模型 API Key 已配置也不会自动解锁。

部署者为自己的服务生成独立体验 Key：

```powershell
node scripts/access-key.mjs
```

脚本在本地 `.env` 设置 `SIGNOVA_ACCESS_KEY`，保留其他已有模型配置；已有有效值时不会覆盖。重启服务后，将这枚 Key 私下发给希望邀请的体验者。体验者在首页的 Key 输入框解锁，随后进入 `/app`。需要自己查看 Key，可在本机终端运行 `node scripts/access-key.mjs --show`，或打开 `.env` 对应行；不要将这个终端画面录入宣传视频。

也可以手动设置 `SIGNOVA_ACCESS_KEY`，要求 16–256 个字符。它与 `DASHSCOPE_API_KEY` / `AI_API_KEY` 相互独立；输入模型密钥不能作为访问资格。不要把体验 Key 写入前端、README 或 Git 提交。

更换 Key：

```powershell
node scripts/access-key.mjs --rotate
```

随后重启服务。原会话随服务重启失效；`.env`、生成的 Key 和模型凭据不进入 Git。

## 默认行为

- `/` 始终是公开展示；已解锁时可选择继续体验。
- `/app`、`/index.html` 和角色页面在未解锁时返回首页；功能脚本、模型资产、模型 API 和语音 WebSocket 同样校验会话。
- 解锁成功发放 HttpOnly、SameSite=Strict Cookie，有效期为 8 小时。服务端只在内存保存随机会话的摘要，重启后全部失效。
- 同一来源地址 10 分钟内连续 5 次错误 Key 后会暂时限制尝试；不信任浏览器伪造的转发地址。
- 功能页有“返回示例”和“退出体验”。返回示例保留当前授权，退出体验撤销授权并关闭语音连接；其他已打开标签页在重新获得焦点或状态检查时回到首页。
- 退出不会删除原有浏览器事项，避免误丢数据。它也不是多人账号隔离；同一浏览器再次解锁仍可访问之前保存的事项。
- 解锁只是进入功能页面。模型调用仍要求服务端模型配置，以及页面里对应的主动启用操作；语音仍需要浏览器权限和安全连接。

## 适用范围

这是项目的默认展示与邀请体验入口，不是 DRM 或源码授权系统。下载源码的人能修改自己的本地程序，也可以为自己部署的服务设置 Key。若需要由项目方决定所有用户的访问资格，应把模型调用和授权服务托管在项目方控制的服务器上，通过 HTTPS 提供访问；静态托管的 GitHub Pages 只能展示页面，不能运行这个 Node 门禁或模型后端。

## 验证

```powershell
node --test test/access.test.mjs test/core.test.mjs test/asr.test.mjs
```

测试使用虚构体验 Key 和模拟模型响应，检查匿名请求、错误 Key、会话撤销、跨站请求、编码路径、限速和语音握手；不会调用付费模型服务。
