# 从初测失败到下一轮验证

## v1 首轮结果

60 条在首次调用前冻结的合成场景，5 组、300 条完整观测、280 次真实模型调用。直接 Qwen 结构化关联与日期通过 57/60（95.0%），原 Agent 55/60（91.7%）；原 Agent 输入 Token 少 14.2%、总 Token 少 14.3%，全观测文本处理均时少 15.3%。它是效率与覆盖的取舍，没有证明准确率提升。

原始输入、输出与失败保留在 `benchmarks/results/qwen-agent-v1/`，未删除或改分；原源码在其中的 `frozen-source/`。首次原版独立包另存为 `deliveries/signova-agent-benchmark-v1.zip`，不覆盖。

## 基于开发问题修复生产链路

1. 扩展常见量词指代与口头更正标记，使“这张 / 那项 / 上回 / 讲错 / 作废”等表达能进入近期话题检索。
2. 泛指需具有事项线索、近期话题或明确选择，减少“这个纪录片 / 这张照片”等无关表达误触发事项澄清。
3. 模型即使对问句返回行动草稿，输出约束也保留问句与参考事项，先澄清而不生成可确认保存的更正。

这些修改来自已知开发失败及产品契约，不将同题回归宣称独立泛化提升。单元回归另用不同表述检查话题关联、无锚点澄清、无关泛指及问句与陈述句的区别。

## v2 验证安排

修复后另建 60 条新合成场景，换用不同事项、材料、原话及资料；标签在调用前冻结。数据作者不查看 v1 模型结果、不运行被测解析器。它仍由同一 AI 辅助开发流程构建，未经独立人工复核，不是外部隐藏测试集。

三组主对照仍使用相同 Qwen、系统契约和可用资料：直接调用、旧关键词检索、修复后的 Agent。保留全部结果及正负变化；v1 与 v2 题目不同，二者的通过率不能直接解释为算法提高了多少。最终对外指标使用 v2 内部同题对照，v1 只说明开发过程与消融。

v2 已完成：三组共 180 条观测、172 次真实模型请求。直接 Qwen 57/60、关键词增强 55/60、完整 Agent 51/60；结构化质量未超过直接 Qwen。当前停止以新测试集反复寻找有利结果，保留失败定位下一阶段的召回与模型核验设计，结论见 [失败归因与可用表达](conclusions.md)。

取消/条件任务、关闭记忆下新建事项等行为按当前产品契约评分；指标未检查材料行动内容和回复措辞，未评估手语或动作。要支持真实用户总体结论，还需要人工复核、独立采样、更多场景和多轮重复。
